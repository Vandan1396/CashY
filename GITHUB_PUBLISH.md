# CashV — GitHub Upload Guide

Upload the contents of this folder to your new GitHub repository.

Files:
- index.html
- style.css
- app.js
- manifest.json
- sw.js
- icons/icon-192.png
- icons/icon-512.png
- README.md
- .gitignore

GitHub Pages:
Settings → Pages → Deploy from a branch → main → /(root) → Save.

If your repository is named `CashV` and your GitHub username is `Vandan1396`, the project-site address will normally be:
`https://vandan1396.github.io/CashV/`
